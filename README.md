## Installation

Clone repository
```bash
git clone https://github.com/Laerrashaqin/Fitology.git
cd Fitology
```

Install dependencies
```bash
npm install
```

Create environment file
Copy `.env.example` to `.env`, then fill in your Firebase and API credentials.

Linux / macOS / Git Bash
```bash
cp .env.example .env
```

Windows Command Prompt
```cmd
copy .env.example .env
```

Run the development server
```bash
npm run dev
```
